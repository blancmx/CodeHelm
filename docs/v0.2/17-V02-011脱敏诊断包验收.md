## 用户流程

设置中新增“脱敏诊断包”。用户选择一个运行会话及最多 7 天的日志时间范围，生成预览、展开条目检查、排除不需要的条目，勾选检查确认后再通过系统保存对话框写入 JSON 文件。默认显示最近 50 个会话，可加载更早会话。

诊断包采用 `codehelm.diagnostic-bundle` 版本 1 的 JSON 格式，不需要解压即可查看清单和条目内容。应用不主动上传、发送或打开外部网站。

## 内容与脱敏边界

- 应用版本与用户选择的时间范围。
- 会话与服务状态、结束码，以及表示曾记录错误的 `SERVICE_ERROR_RECORDED` 分类码。服务统一编号，不导出原始名称、PID、进程指纹或自由文本错误消息。
- 当前方案的只读环境检查，仅导出检查代码、状态和检查时间。明确区分当前检查与故障发生时的历史状态；不导出诊断详情、参数、建议文本或秘密指纹。
- 有限历史日志：复用既有受文件边界保护的 Worker 读取，读取一页，再按日志行提供勾选；最多 200 行。
- 读取清单包含扫描字节、不可读/缺失文件数量、跳过记录、截断记录、后续分页、存储错误标记。计数来自实际读取结果；不导出原始文件路径。整个读取失败时报告“数量未知”，不会以 0 伪装完整。
- 不导出源码、数据库原件、环境变量字段、命令参数字段、项目和服务名称。日志先处理路径、凭据字段、URL、邮件地址、私钥，再替换当前方案与继承环境中的已知值。生成的路径占位符在同一包中保持一致。
- 当前方案已删除、秘密无法解密或替换表超出预算时，省略全部日志正文，仍提供可获得的状态与读取清单。已删除或历史上变更过的未知秘密无法由当前配置恢复；界面明确要求检查自定义敏感文本并允许逐项排除。
- 自动规则不是任意秘密识别器，编码、拆分或自定义格式的敏感数据仍可能需要人工排除。

## 冻结、取消与资源预算

- 预览只在主进程内保留脱敏后的内容。令牌绑定调用窗口，5 分钟有效，导航、窗口销毁、显式取消及成功导出后失效。
- 保存只接受令牌与条目 ID，不接受渲染进程提交的正文或输出路径。导出不会重新读取新增日志，写入内容来自固定预览。
- 系统保存对话框取消不写文件；应用取消也会阻止尚未开始的导出。预览取消时底层读取可能在其既有超时预算内结束，但不会自动保存。
- 上限：7 天、200 行、单段脱敏正文最多 4096 字符、序列化文件 1 MiB；达到上限显示提示。最多同时处理 2 个预览，每窗口互斥；最多保留 10 个预览。
- 已知值替换表最多 1024 个非空值、合计 64 KiB，超过时省略正文。先处理完整路径，避免 `SystemDrive=C:` 等短环境值破坏后续路径识别。
