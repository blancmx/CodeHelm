## 2. 本轮实现

入口：项目详情 → 环境诊断 → 检查运行环境。

- 检查项目目录、服务工作目录、路径物理边界、启用服务与循环/缺失依赖。
- 查找明确命令路径、工作目录或服务 PATH 中的命令文件，不执行命令。
- 检查已配置环境变量是否为空，仅返回数量，不返回值。
- 使用既有端口绑定检查报告端口可用性，不预留端口、不结束占用者。
- 检查当前服务目录的锁文件与 node_modules/.venv 元数据，多包管理器线索冲突显示警告。
- 每项输出通过、警告、阻断、未确定或不适用，以及原因和下一步建议；问题优先排序。
- 结果参考有效期为 1 分钟；修改方案后清空旧结果；未保存的方案禁止检查，避免误把旧配置结果当作新配置结果。
- 同一页面检查期间禁止重复请求；项目/方案切换与组件销毁后丢弃过期响应。
- IPC 只接受保存的方案 UUID，主进程查询项目路径；检查结束后复核方案与路径未变化。
- 复用已有读取任务并发限制和 5 秒超时，每个方案最多检查 32 个启用服务、512 个文件元数据候选；超时/失败不显示完成。
- 指纹使用进程内随机 HMAC 密钥，避免输出可用于猜测低熵秘密的普通哈希；指纹不是启动授权令牌。
- 浏览器预览明确提示不支持本机诊断，不返回模拟通过结果。

## 6. 单次运行时版本检查（2026-09-07）

### 6.1 本轮实现

在环境诊断页新增 Node.js、Python、Java 选择与“选择并检查版本”入口。用户通过本机文件选择框指定运行时，再通过默认取消的原生确认框查看程序路径、固定参数与 SHA-256 摘要。本次确认只允许一次版本检查，不保存永久信任，也不产生 Runner 启动审批。

- IPC 仅接受已保存方案 ID 和运行时类型，不接受渲染进程传入的可执行路径、参数或环境变量。
- 解析物理路径，拒绝当前项目目录内的程序，仅接受与所选类型一致的 node.exe、python.exe、java.exe；拒绝 wrapper、cmd、bat。文件名不证明程序可信，可信来源由用户明确确认。
- 确认前后以及执行后对文件进行有界摘要检查；每次最多读取 256 MiB，分块检查取消与 10 秒截止信号。检测到文件或方案变化即丢弃结果。
- 使用无 shell 的子进程，在独立临时目录中执行固定参数：Node `--version`、Python `-I -S --version`、Java `-version`。环境仅保留系统和临时目录变量，PATH 为空，不传入项目变量或 NODE_OPTIONS、PYTHONPATH、JAVA_TOOL_OPTIONS 等注入变量。
- 执行超时 3 秒，输出上限 4 KiB，只展示解析出的版本，不回传原始输出。窗口关闭、导航或渲染进程退出会触发取消。
- 全局一次只接受一个检查；方案修改或组件卸载后丢弃迟到结果。临时目录只尝试非递归删除，避免递归处理所选程序产生的文件。

## 7. 显式运行时路径与 Node 版本声明匹配（2026-09-07）

### 7.1 已实现的行为

单次运行时检查完成后，按已保存方案中的启用服务逐项展示路径匹配和声明比较。只在服务显式可执行路径解析后与所选程序物理路径一致时使用该版本；PATH 简写、npm/pnpm、wrapper 等间接调用保留“路径未确定”，其他显式路径标记“所选程序不同”。没有为这些候选增加执行权限。

对于匹配的 Node 服务，仅读取该服务工作目录内的 `package.json`，核对 `engines.node`，展示声明来源与版本要求。结果分为“满足声明、不满足声明、未声明要求、版本兼容性未确定”。缺少清单或字段不等于兼容；损坏 JSON、错误字段类型、读取失败或不支持的语法均为未确定，不回传原始异常或不支持的字段内容。

版本结果有效期 1 分钟，过期有显式提示；方案变化仍清空结果。每次重新选择并确认检查都会重新读取清单，因此修改声明后不复用旧比较结果。当前是诊断参考结果，不并入自动启动预检，不改变启动授权或自动安装行为。

版本字段依据 [npm package.json engines 文档](https://docs.npmjs.com/cli/v11/configuring-npm/package-json/#engines)。当前只实现以下有限语法，未引入 semver 依赖：

| 支持范围 | 示例 |
| --- | --- |
| 稳定完整版本号与比较符 | `24.16.0`、`>=22.12.0 <=24.16.0` |
| 完整版本的 caret / tilde | `^22.1.0`、`~24.1.0`；包含零主版本边界 |
| 空白连接的且、双竖线连接的或 | `>=22.12.0 <25`、`^22.1.0 || ^24.0.0` |
| `>=` 和 `<` 的部分版本下界扩展 | `>=22`、`<24.17` |
| 通配全部稳定版本 | `*` |

预发布、构建元数据、x-range、连字符范围、部分 caret/tilde、`<=22` / `>22` 等均暂不支持。整个表达式必须可解析；一个 OR 分支有效、另一个无效时仍返回未确定。字符串最多 256 字符、8 个 OR 分支、每分支 16 个条件，数值分量限制为 8 位，不接受前导零。

依据 [Python 版本规范](https://packaging.python.org/en/latest/specifications/version-specifiers/) 和 [pyproject.toml 规范](https://packaging.python.org/en/latest/specifications/pyproject-toml/)，当前实现稳定版本的有限比较范围：

| 支持语法 | 行为示例 |
| --- | --- |
| `>=`、`<=`、`>`、`<`、`==`、`!=` | `>=3.10, <4`；用逗号连接，所有条件都需满足 |
| 等于/排除的前缀通配 | `==3.13.*`、`!=3.12.*` |
| `~=` 兼容范围 | `~=3.10` 接受 3.x 且不低于 3.10；`~=3.10.1` 限于 3.10.x |
| 版本数字补零比较 | `==3.13` 可匹配 3.13.0，但不匹配 3.13.1 |

限制为 1～3 段数字、每段最多 8 位；声明最多 256 字符、16 个条件。预发布、开发版、post/local、epoch、任意相等 `===`、环境标记以及其他不支持的表达式均为未确定，而非不满足。

`project.dynamic` 包含 `requires-python` 时保留未确定；字段类型错误、重复键和损坏 TOML 也不判为通过。不会执行 setup.py、构建后端或任何项目代码来补全动态元数据。未声明标准字段时明确显示“未声明要求”，不从 Poetry 专有字段、Pipfile、setup.cfg 或父目录补推。

## 9. Maven Java 构建 JVM 声明诊断（2026-09-07）

### 9.1 本轮实现

Java 单次检查在显式运行时路径匹配后，读取服务目录的 `pom.xml`。本轮仅比较本地 `maven-enforcer-plugin` 单个 `enforce` 执行中 `configuration.rules.requireJavaVersion.version` 的声明。结果来源标明“构建 JVM”，并说明未验证 Maven 实际使用此程序，也不代表项目运行兼容性。

此区分依据 [Maven Compiler 说明](https://maven.apache.org/plugins/maven-compiler-plugin/index)：编译目标与实际运行 Maven 的 JDK 不是同一项配置。因此 `java.version`、`maven.compiler.source/target/release` 不直接作为运行时版本要求。

范围依据 [Enforcer 版本范围](https://maven.apache.org/enforcer/enforcer-rules/versionRanges.html) 及 [Require Java Version](https://maven.apache.org/enforcer/enforcer-rules/requireJavaVersion.html)，本轮只支持 Java 9+ 的整数边界：裸 `17` 表示至少 17，`[17,22)`、`[21,)`、`(,21]`、`[21]` 等单一区间。`[21]` 不等于所有 21.x，例如 21.0.5 不匹配 `[21]`。Java 8 的旧版本映射、带小数的范围边界、区间并集、预发布和带构建后缀的版本暂为未确定。

支持的 POM 结构刻意有限：不能包含 parent、profiles 或 pluginManagement；只允许一个 Enforcer 插件、一个 enforce 执行，phase 省略或为 validate，配置只含 rules。合并配置、skip 等执行选项、自定义规则选项和变量引用不做推断。仅有编译配置时显示未声明此项要求。

新增独立的严格 XML 诊断解析入口，复用已有依赖但不改变原分析器 parseXml 行为。解析前验证 XML，拒绝 DTD 和实体声明，关闭实体处理与标签数值自动转换；继续使用原生项目边界和 64 KiB 文件读取限制。不会运行 Maven、Gradle、wrapper 或构建脚本来生成 effective POM。
