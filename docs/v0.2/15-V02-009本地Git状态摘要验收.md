# V02-009 本地 Git 状态摘要

日期：2026-09-12。

## 范围与入口

项目详情“项目概览”新增本地 Git 状态卡片。进入卡片时读取一次，用户可点击“刷新 Git 状态”；不轮询，不自动 fetch、pull、push、提交或切换分支。查询错误不会阻断项目分析、配置编辑或启动。

展示当前分支、分离 HEAD、尚无提交状态、未提交路径总数、已暂存/未暂存/未跟踪/冲突数量、最近提交短哈希及摘要、实际仓库根目录、查询开始时间。嵌套项目展示所属整个仓库，避免把仓库总数误解为当前子目录数量。

本阶段不展示 ahead/behind，避免将旧远端跟踪引用误解为当前远端状态。

## 只读实现

主进程仅接受项目 UUID，从数据库读取项目目录；渲染端不能传入自定义 Git 子命令、可执行文件或环境变量。自动定位本机 Git 时优先常规系统安装目录，再检查绝对 PATH 条目，排除项目目录内的程序与相对 PATH。执行使用绝对程序路径、`shell=false`、`windowsHide=true`，不加载项目运行环境。

原仓库仅执行固定的 `rev-parse`、`symbolic-ref` 和 `config --no-includes` 元数据读取。工作树状态在临时 Git 元数据目录中查询：

1. 创建独立的索引与 HEAD 副本，重新建立当前分支引用。
2. 生成受限配置，仅保留允许的布尔/枚举文件比较设置及 SHA-256 对象格式设置。
3. 通过 objects alternates 读取原仓库对象，不复制或修改原对象库。
4. 使用 `ls-files`、`check-attr` 检查是否涉及内容过滤；有过滤属性或特殊编码时返回不支持，不执行驱动。
5. 使用 `status --porcelain=v2 -z --untracked-files=all --ignore-submodules=all --no-renames` 读取可解析状态，使用固定 `log -1` 格式读取当前提交摘要。
6. 完成后重新核对原索引身份、HEAD 对象及分支；查询期间变化时显示未知，不返回混合状态。
7. 删除本次创建的临时目录；临时目录不写入原仓库。

所有 Git 调用关闭可选锁、fsmonitor、hooks、自动维护、自动 GC、交互提示、分页、替换对象和延迟取回对象，远端协议设置为禁止。环境不继承 `GIT_CONFIG_COUNT`、`GIT_DIR`、外部 diff、SSH 等注入变量，也不读取机器级 Git 配置。

设计依据：[Git status 的 porcelain 和后台刷新说明](https://git-scm.com/docs/git-status)、[Git 环境变量与可选锁说明](https://git-scm.com/docs/git)。本功能的安全边界由固定调用、配置副本及回归测试共同验证，不能仅凭命令名叫 status 就认为一定无副作用。

## 统计语义与限制

- 未跟踪目录按文件展开，忽略文件不计数；使用工作树 `.gitignore` 和仓库 `info/exclude`。
- 不加载机器级配置和全局忽略规则，结果可能与叠加个人全局规则的终端不同，卡片明确提示。
- 一个路径同时有暂存和未暂存修改时，总数只计一次，两个分项各计一次。
- 关闭重命名推断，因此重命名按删除和新增分别计数；这是一项有意的有界查询选择。
- 子模块内部变化不纳入统计；卡片明确说明。
- 配置包含、内容过滤器、特殊工作树编码、稀疏检出、共享索引、部分克隆、自定义属性/忽略文件及 worktree 扩展配置当前返回“不支持”。普通 linked worktree 与 detached HEAD 支持。
- 单次查询使用八秒取消信号，Git 子进程输出最多 8 MiB；索引副本最多 8 MiB，仓库排除规则最多 64 KiB。超限或超时显示未知，不将部分结果计为干净。
- 每个窗口最多一个查询，应用同时最多两个；页面导航或窗口销毁会取消查询，迟到结果不写回新项目卡片。
- 时间代表本次查询开始时间，不是持续监控时间；工作区后续修改需要手动刷新。

## 验收矩阵

| 验收项 | 方法 |
|---|---|
| 初始空仓库与未跟踪中文文件 | 真实 Git 初始化与摘要断言 |
| 暂存/未暂存并存、最近提交 | 真实 Git 提交及修改 |
| 查询前后源文件、索引、refs、配置不变 | 全仓库文件摘要与修改时间清单比较 |
| linked worktree、嵌套项目、分离 HEAD | 真实 Git worktree 与 checkout 夹具 |
| hooks、fsmonitor、远端 helper 不执行 | 外部 helper 标记文件与元数据不变检查 |
| 内容过滤器、无驱动的过滤属性 | 返回 unsupported，拒绝伪造干净状态 |
| 非仓库、缺失可执行文件、取消、超时、超大索引 | 错误分类和边界回归 |
| NUL 文件名、重命名、冲突格式解析 | 独立解析测试 |
| 仓库忽略规则与 info/exclude | 真实文件夹具 |
| 进入详情、手动刷新、浅色主题、异常降级 | 真实 Electron 交互与截图 |
